# SkyCast Weather Dashboard

A responsive weather dashboard for the COSC32133 / BECS32263 Full-Stack Software Development lab.

## Run the project

Open `index.html` in a modern browser. The dashboard uses the free Open-Meteo service, so an internet connection is needed for live weather data.

## Features

- City search and convenient popular-city buttons
- Current temperature, feels-like value, humidity, wind, pressure, visibility, sunrise, and sunset
- Five-day forecast
- Celsius/Fahrenheit toggle and browser location lookup
- Responsive layout, with the required site header and footer
